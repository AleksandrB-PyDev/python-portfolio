Мои проекты, написанные в процессе изучения Python.

## 🗂 Проекты

### 1. База данных студентов (SQLite)
Приложение для управления студентами (CRUD) на SQLite с экспортом в CSV.
- Технологии: Python, SQLite, ООП.

### 2. Парсер вакансий
Скрипт, который собирает вакансии с сайта python.org и сохраняет их в CSV.
- Технологии: Python, Requests, BeautifulSoup.

### 3. Трекер расходов
Консольное приложение для учёта личных финансов, написанное на Python.
Позволяет записывать траты, группировать их по категориям и анализировать общую сумму расходов.

-Технологии Python, SQLite, ОПП.
